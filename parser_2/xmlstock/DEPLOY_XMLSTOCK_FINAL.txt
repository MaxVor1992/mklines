Быстрый порядок внедрения:
1) Сделайте резервную копию текущих файлов.
2) Замените файлы из архива в директории /mklines/public_html/parser/
3) Проверьте, что права доступа у файлов обычные для текущего проекта.
4) Выполните живую проверку с сервера:
   python3 check_xmlstock_live.py окна
5) Откройте интерфейс парсера и проверьте:
   - engine=12 -> Яндекс XML
   - engine=13 -> Яндекс Live
   - engine=22 -> Google XML
   - TOP-10 / TOP-20 / TOP-30
   - docache on/off

Что изменено:
- XMLRiver исключён из рабочих маршрутов main.py для engine 12 и 22.
- engine 13 переведён на Яндекс Live XMLStock.
- Названия движков в интерфейсе приведены к: Яндекс XML / Яндекс Live / Google XML.
- Кеш перенесён на модульный уровень в xmlstock.py, чтобы реально работать между повторными запусками в рамках TTL из parser_app/for_cache.py.
- Добавлена обработка повторных запросов для Яндекс XML при кодах 202/210 и ретраи для Яндекс Live / Google XML при временных ошибках.

Ограничение проверки:
Из этой среды не удалось выполнить живые HTTP-запросы к xmlstock.com, поэтому финальную сетевую проверку нужно сделать на вашем сервере через check_xmlstock_live.py.
